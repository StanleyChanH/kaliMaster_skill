# Code of Conduct

## Our pledge

We are a security-research community project. We pledge to keep participation
respectful, inclusive, and harassment-free for everyone regardless of
background or identity.

## Standards

**Encouraged**
- Precise, evidence-backed technical claims (versions, flags, outputs)
- Helping newcomers through the `good first issue` i18n tasks
- Assuming good faith, especially in language barriers — many contributors
  work across Chinese/English

**Unacceptable**
- Harassment, personal attacks, or discriminatory language
- Using project channels to seek help attacking systems you don't have
  authorization to test
- Posting live third-party targets, real credentials, or client data in
  issues/PRs

## Enforcement

Report violations by opening a *private* security advisory
(Settings → Security → Advisories) titled `conduct:` — or contact the
maintainer directly. Reported information stays confidential.

Enforcement may include warning, temporary ban, or permanent exclusion.
